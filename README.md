# 🎓 LearnHub LMS

A modern **Learning Management System (LMS)** built using the **MERN Stack**. LearnHub allows students to book lessons, tutors to create and manage courses, and admins to manage the platform.

---

# 💻 Installation

## Clone Repository

```bash
git clone https://github.com/johnbalaji786/learnhub-lms.git
```

---

## Backend

```bash
cd server

npm install

npm run dev
```

---

## Frontend

```bash
cd client

npm install

npm run dev
```
